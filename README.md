# tikhori

Artisanal Indian Spices E-Commerce & Brand Platform — Inspired by traditional craftsmanship with a vibrant, maximalist artisanal aesthetic.

## Features
- **Frontend**: React 18, Vite 5, Tailwind CSS, Framer Motion, Lucide Icons
- **Backend**: Node.js, Express, MongoDB (Mongoose), JWT Authentication
- **Infinite 3D Product Stage**: Floating spice pouch viewer with drag physics and real-time interaction
- **Storefront**: Spice collection filtering, search, sorting, dynamic weight selection, reviews
- **Admin Management Suite**:
  - Live analytics & revenue stats
  - Product Catalog CRUD
  - Order status tracking & updates
  - Stockist Locator manager
  - Customer contact enquiries & newsletter subscribers

## Getting Started

### 1. Install Dependencies
```bash
npm run install:all
```

### 2. Configure Environment
Copy `server/.env.example` to `server/.env` and update your MongoDB connection string.

### 3. Run Development Servers
```bash
npm run dev
```
- Client runs on `http://localhost:5173`
- Server runs on `http://localhost:5000`
